# 📚 Library Catalog

Веб-приложение для ведения электронного каталога библиотеки с административной панелью, системой хранения данных и современным интерфейсом.

---

# 🚀 Возможности

- 📖 Просмотр каталога книг
- 🔍 Поиск по библиотеке
- 🗂 Категории и фильтрация
- 👨‍💼 Административная панель
- ➕ Добавление и редактирование книг
- 🗑 Удаление записей
- 💾 SQLite база данных
- 🌐 REST API на Flask
- 🎨 HTML/CSS/JS интерфейс

---

# 🛠 Используемые технологии

| Технология          | Назначение  |
| ------------------- | ----------- |
| Python 3            | Backend     |
| Flask               | Веб-сервер  |
| Flask-CORS          | Работа API  |
| SQLite              | База данных |
| HTML/CSS/JavaScript | Интерфейс   |

---

# ⚙️ Установка и запуск

## 1. Установите Python

Скачать можно с официального сайта:

[https://www.python.org/downloads/](https://www.python.org/downloads/)

Во время установки обязательно включите:

```text
Add Python to PATH
```

---

## 2. Скачайте проект

Распакуйте проект в удобную папку, например:

```text
D:\LibraryCatalog-main
```

---

## 3. Запустите проект

Откройте терминал в папке проекта и выполните:

```bash
.\start.bat
```

При первом запуске автоматически:

- установятся зависимости,
- создастся база данных SQLite,
- запустится Flask сервер.

# 👤 Администратор

Учётные данные администратора задаются в файле:

```text
create_admin.py
```

По умолчанию:

```text
Логин: Юрий Андрущенко
Пароль: 123123
```

---

# 🗄 База данных

SQLite база создаётся автоматически:

```text
backend/library.db
```

Файл базы данных не добавляется в Git.

---

# 📦 Установка зависимостей вручную

Если какой-либо модуль отсутствует:

```bash
pip install -r backend/requirements.txt
```

Если появляется ошибка:

```text
ModuleNotFoundError
```

можно установить пакет отдельно:

```bash
pip install flask-cors
```

---

# ▶️ Запуск сервера вручную

Если `start.bat` не работает:

```bash
cd backend
python app.py
```

---

# 🛑 Остановка сервера

В терминале нажмите:

```text
CTRL + C
```
